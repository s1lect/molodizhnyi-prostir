# Сайт молодіжного простору «Повір у себе» (Степанівський ліцей)

Статичний сайт для GitHub Pages.

- `index.html` — сама сторінка: оформлення, трейлер, анімації, тексти розділів і правила простору;
- `anketa.html` — дві вбудовані анкети: реєстрація учасника (`anketa.html?f=reyestratsiia`) і пропозиція активності (`anketa.html?f=propozytsiia`). Запитання лежать на початку скрипта в цьому файлі, у блоці `FORMS`;
- `dani.js` — контакти, анкети та документи. Усе, що змінюється регулярно, редагується тут;
- `img/` — фотографії ліцею.

## Як опублікувати

1. Створіть на GitHub новий публічний репозиторій (наприклад, `molodizhnyi-prostir`).
2. Натисніть **Add file → Upload files** і перетягніть туди `index.html`, `anketa.html`, `dani.js`, `README.md` та папку `img`. Підтвердіть кнопкою **Commit changes**.
3. Відкрийте **Settings → Pages**. У полі **Source** оберіть **Deploy from a branch**, гілку `main`, папку `/ (root)` і натисніть **Save**.
4. За хвилину-дві сайт відкриється за адресою `https://ВАШ-ЛОГІН.github.io/molodizhnyi-prostir/`.

## Форма відгуків та анкети

Форма відгуків і обидві анкети надсилають повідомлення на адресу з поля `email` у `dani.js` через безкоштовний сервіс FormSubmit. Поки адреса порожня, кнопка «Надіслати» вимкнена.

1. Впишіть адресу: `email: "vasha-adresa@gmail.com",`.
2. Відкрийте опублікований сайт і надішліть перший тестовий відгук.
3. На цю пошту прийде лист від FormSubmit із проханням підтвердити адресу. Натисніть у ньому кнопку підтвердження. Після цього всі відгуки надходитимуть у вашу скриньку.

## Таблиця з відповідями

Щоб анкети й відгуки записувалися в Google Таблицю (аркуші «Учасники», «Пропозиції», «Відгуки»), розгорніть скрипт `tablytsia-vidpovidei.gs` як вебзастосунок у своїй таблиці і впишіть його адресу в поле `tablytsia` у `dani.js`. Після цього FormSubmit більше не використовується.

## Як додати анкету

1. Створіть форму (наприклад, у Google Forms) і скопіюйте посилання на неї.
2. На GitHub відкрийте `dani.js` і натисніть олівець (**Edit**).
3. У списку `ankety` скопіюйте блок від `{` до `},`, вставте його нижче і змініть текст:

```js
{
  nazva: "Які гуртки вам потрібні?",
  opys: "5 запитань, до 3 хвилин.",
  posylannia: "https://forms.gle/...",
  do: "2026-12-20"
},
```

4. Натисніть **Commit changes**. Сайт оновиться за хвилину.

Після дати з поля `do` анкета сама позначиться як завершена.

## Як додати документ

У списку `dokumenty` в `dani.js` скопіюйте блок і змініть назву, опис та посилання. Власне положення про простір можна завантажити в репозиторій як PDF і вказати посилання на нього.

## Спокійний режим

Кнопка «Спокійний режим» угорі перемикає сайт на теплі м'які кольори й вимикає всі анімації. Вибір запам'ятовується в браузері відвідувача.

## Як змінити тексти та фото

Тексти трейлера, розділів і правил лежать у `index.html`: змінюйте лише текст між тегами. Щоб замінити фото, покладіть новий файл у `img/` під тією самою назвою (`licei-1.png`).
